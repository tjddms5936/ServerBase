# 승인 RF의 실제 FastAPI 연결 검사

실제 Uvicorn을 로컬에서 실행해 직접 모델 계산과 HTTP 응답을 대조했다.
학습·공식 Test·수집 레코드는 열지 않았고 직접 만든 snapshot만 사용했다. 탐지 성능 평가가 아니다.

| 요청 | HTTP | label | 이상 점수 |
| --- | ---: | --- | ---: |
| paced_snapshot | 200 | normal | 0.0 |
| rapid_snapshot | 200 | controlled_anomaly | 0.8634681690815189 |
| first_snapshot | 200 | normal | 0.63324627266136 |
| unsupported_summary | 422 | 판단 없음 | 해당 없음 |
| invalid_input | 422 | 판단 없음 | 해당 없음 |

세 메시지 응답은 직접 RF 계산과 정확히 일치했다. 요약에는 가짜 정상 판단을 반환하지 않았고 잘못된 입력도 422로 거부했다.
생성한 프로세스만 quit 입력으로 정상 종료하고 승인 파일·구현 해시를 재검증했다.

## 한계와 다음 작업

수작업 snapshot의 HTTP 기능 검사이며 새 데이터셋 성능이나 독립 Test 평가가 아니다.
C++ 송수신·큐·결과 저장·부하·장애는 다음 단계에서 별도로 검증한다.
승인은 로컬 참고용이며 자동 차단·실제 운영·malformed 탐지 보장을 뜻하지 않는다.

다음은 실제 C++ TCP 요청·결과 저장·오류·지연·큐 포화·종료·부하 검증이다. 남은 큰 단계는 2개다.
