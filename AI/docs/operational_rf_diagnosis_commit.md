## 검증

- 신규 단위·통합 테스트 15개 통과.
- 전체 테스트 277개 통과: `python -X utf8 -m unittest discover -s tests -p 'test_*.py'`.
- 고정 실제 모델의 진단 실행 완료. 재학습·새 threshold 탐색·수집·새 Test 평가 미실행.
- Train/Validation 전체 2,051행, FP/FN 152행과 원본 식별자·오분류 분류 일치.
- 보호 입력·모델·코드 27개와 출력 4개 SHA-256 검증, 기존 잠금 유지.
- `git diff --check` 통과. Git의 LF/CRLF 변환 안내는 공백 오류와 구분.

## 커밋 범위
